# Pilot screenshot acceptance set

These PNGs are direct simulator captures from the build-10 Debug mock routes on
an iPhone 16e (390 × 844 points, 3× backing scale). They are implementation
acceptance references for `LessonCheckScreen`, reviewed against the behavior,
copy, hierarchy, and inherited tokens in the parent handoff.

The filenames match `WC_ROUTE`. Long source-authority screens intentionally
capture the initial viewport; all remaining authority content is scrollable.
